## Papers

### `alympics-2311.03220v3.pdf`

**Alympics: LLM Agents Meet Game Theory** — Wu et al., COLING 2025 (arXiv 2311.03220v3, microsoft/Alympics).

Most directly relevant prior work for this project: 5 LLM agents playing a
multi-round survival auction (Water Allocation Challenge). Uses GPT-4 only;
doesn't compare across providers; doesn't use an AMM. Key takeaways for us:

- Survival framing eliminates the end-game dump-spiral we have.
- Agent heterogeneity (different needs / salaries) produces richer strategies.
- Persona / role-play in the prompt is mostly cosmetic (alignment 3.5/5).

Downloaded from <https://arxiv.org/pdf/2311.03220v3>.
